OPN FlowVault

A simple native OPN vault built for OPN Testnet.

Overview

OPN FlowVault demonstrates a basic DeFi primitive on OPN Chain. Users can deposit native OPN into a smart contract, track their on-chain vault balance, and withdraw their funds anytime.
